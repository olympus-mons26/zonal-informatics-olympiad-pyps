# zonal-informatics-olympiad-pyps
This repository contains the previous year papers as-well-as the solutions of the Zonal Informatics Olympiad (ZIO) from 2003 to 2026.

## ICO Current 

See [https://www.iarcs.org.in/inoi/current.php](https://www.iarcs.org.in/inoi/current.php) for more details.

## How to use?

Just clone the Github Repository by using `git clone https://github.com/olympus-mons26/zonal-informatics-olympiad-pyps.git` or by downloading the .zip file and extracting it. 

Papers are in the `/papers ` folder and the solutions are in the `/solutions`  folder.
